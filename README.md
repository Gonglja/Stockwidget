# StockWidget (Qt / C++)

一个在 **Windows** 上运行的极简透明盯盘浮窗 —— 按指定股票代码实时显示行情表格，可选展示当日迷你 **K 线**，支持沪深京三市。

本项目是原版 [**sbr0574/StockWidget**](https://github.com/sbr0574/StockWidget)（PySide6 / Python）的 **Qt 6 + C++ 重构版**：保留全部功能与配置格式，重写为原生应用并针对卡顿做了架构级优化。

> 适合贴在屏幕一角随时查看 👀

---

## ✨ 功能

* **透明无框浮窗**：置顶显示，按住任意位置拖动，**单击隐藏**（双击亦可），右键打开菜单。
* **系统托盘**：左键切换显示/隐藏；右键菜单含「设置 / 退出」。
* **表格展示**（列可自由开关）：`代码 | 名称 | 现价 | 涨跌值 | 涨跌幅 | 买一 | 卖一 | 委比 | 成交量 | 成交额 | 均价 | K线`
  * 现价触及当日最高/最低时显示 `↑ / ↓`
  * 买一/卖一显示模式：`数量 / 价格 / 数量和价格`；集合竞价显示「配对量 / 未配对量」
* **默认颜色**：开启后自动 **红涨绿跌**；关闭则为单色模式（自定义文字颜色）。
* **列开关与表头/网格**：右键浮窗即时切换。
* **字体与行距**：字号 8–15 pt；行高 = 字高 + 行距；K 线尺寸随字号同步缩放。
* **刷新间隔**：1/2/3/5/10/15/30/60 秒。
* **显示 / 请求时段**：显示与请求可**分别**设置为「一直 / 开盘时段（周一~五 9:15–15:00）/ 自定义时段」；进入显示时段自动出现、离开自动隐藏；非请求时段不拉取数据（保留上次）。
* **贴边隐藏**（可选）：鼠标离开后自动就吸到屏幕边缘（**方向可选：自动就近 / 左 / 右 / 上 / 下**），只在边缘留 4px 细条；鼠标划过细条即恢复。开启后单击隐藏自动禁用。
* **股票代码管理**：设置面板内增/删/改/上移/下移，自动**规格化**并去重（`600000`→`sh600000`，`000001`→`sz000001`，`8xxxxx`→`bjxxxxxx`）。
  * 顶部**搜索框**：输入代码（**可不带前缀**）直接添加；或输入**名称/片段**（如「浦发」「6000」）**模糊搜索**，从下拉结果中点选加入。
* **名称显示与自定义映射**：名称列可设为「全称」或截断 1~4 字；可为任一代码指定**自定义显示名**（设置面板双击自选项，或在浮窗某一行上右键「自定义名称…」，留空即恢复行情名称）。别名优先于行情名称，且不受名称截断影响。
* **点击表头排序**：点任意指标表头 → 降序，再点 → 升序，第三次 → 取消排序回到自选顺序；排序状态自动保存，每次刷新实时重排（同值行保持自选顺序）。
* **右下角配置按钮**：浮窗右下角的 **⚙ 圆环**（悬停变亮）→ 打开「**自定义配置**」对话框：上半区**排序**（指标 + 降序/升序/不排序），下半区**自定义名称**表格（`代码 | 自定义名称`，留空 = 使用行情名称）；改动**即改即生效**。不想要这个按钮：浮窗右键 → 取消勾选「显示配置按钮」。
* **其他**：全局快捷键（默认 `Ctrl+Alt+F`，设置面板内可改，**改后即时生效**）、开机启动、程序图标选择、位置记忆、自动保存配置；浮窗隐藏时暂停刷新。

## ⚡ 相对原版的性能改进

原版卡顿的根因是**架构**问题，重构时逐条改掉：

| 卡顿点 | 原版 | 本版 |
|---|---|---|
| 刷新 | GUI 线程同步 `requests.get`，每次全量重置模型、全表重算列宽 | `QNetworkAccessManager` **异步**请求（超时 3s，GUI 线程不阻塞）；模型**逐单元格 diff**，只发 `dataChanged`；列宽/行高**缓存**，刷新路径零 `resizeColumnsToContents`、零 `setStyleSheet` |
| 拖动 | 每次鼠标移动都 `raise_()`，另有每秒置顶定时器 | 拖动期间只 `move()`；**移除**每秒置顶轮询 |
| 设置面板 | 每次打开都重建对话框、枚举全系统字体、切页 `setFixedSize` 重排 | 对话框**单例常驻**、标签页**懒构造**、字体列表**缓存** |

## 🧰 运行环境

Windows 10/11（x64）。

* **Qt 6.11.1**（`msvc2022_64` 套件）
* **Visual Studio 2022**（MSVC 14.44+）与 **CMake**、**Ninja**
* 依赖 Qt 模块：`Core Gui Widgets Network Core5Compat`（测试另需 `Test`）

> **无第三方库**：全局快捷键用 Win32 低层键盘钩子 `WH_KEYBOARD_LL`，开机启动用注册表。

## ▶️ 构建、测试与打包

```powershell
# 构建
scripts\build.cmd

# 运行
build\StockWidget.exe

# 单元测试（QTest）
scripts\test.cmd

# 打包为便携文件夹（exe + Qt DLL）
scripts\package.cmd      # 输出到 dist\
```

若 Qt 路径不同，设置环境变量 `QT_DIR` 即可（本机默认 `C:/1/Qt/6.11.1/msvc2022_64`）：

```powershell
$env:QT_DIR = "D:/Qt/6.11.1/msvc2022_64"
scripts\build.cmd
```

## 🚀 发布（GitHub Actions）

推送 `v*` 标签即**自动编译并创建 Release**：

```bash
git tag v1.5.0
git push origin v1.5.0
```

流程见 `.github/workflows/release.yml`：

1. 安装 Qt **6.8.3 LTS**（`msvc2022_64` + `qt5compat`）
2. `scripts\build.cmd` 构建
3. `scripts\test.cmd` 跑全部测试
4. `scripts\package.cmd` 用 `windeployqt` 打包
5. 上传 `StockWidget-<tag>-win64.zip` 并创建 Release（自动生成变更说明）

也可在 Actions 页**手动触发**（`workflow_dispatch`，只出 artifact、不建 Release）。
CI 通过环境变量 `QT_DIR` 指定 Qt 路径；MSVC 环境由 `scripts\_vcvars.cmd` 经 `vswhere` 自动定位。

> **为什么 CI 用 6.8.3 而不是 6.11.1：** aqtinstall 目前无法安装 6.11.x —— 官方源 `qt6_6111` 分支的顶层 `Updates.xml` 缺失（404），而 6.10.3 / 6.8.3 正常。
> 本项目 `find_package(Qt6 6.8)`，本机已用 **6.8.3 完整构建 + 7/7 测试通过**验证。本机脚本默认仍是 6.11.1（可用 `QT_DIR` 切换）。

## ⚙️ 设置面板

* **自选列表**：**两列显示（代码 / 名称）**，名称列 = 自定义名称优先，没有则显示本页自己拉到的行情名（再回落到浮窗已抓到的名字，都没有则留空，**只读**）；增/删/改/上移/下移 + 勾选要在浮窗中显示的股票；顶部搜索框支持「不带前缀的代码」直接添加与「名称/代码片段」模糊搜索点选；**双击某项**可同时改代码与该代码的自定义名称（留空 = 使用行情名称）。
  * 名称列**不受「请求时段」限制**：打开设置时批量拉一次、添加代码时拉一次、切回该页再补一次；从搜索联想里选中的股票**直接带出名称**（零额外请求）。
* **显示数据**：刷新间隔；12 列独立开关；名称显示长度（全称 / 1~4 字）。
* **外观**：默认颜色/单色、文字色、背景色、背景不透明度 0–100%、整体不透明度 20–100%、字体、字号、行距。
* **常规**：开机启动、**全局快捷键（可视化录制，即时生效）**、程序图标、**显示时段 / 请求时段**、**贴边隐藏**。
  * **程序图标、全局快捷键、开机启动改完立即生效**（无需重启、无需等下一次操作）。

修改**实时生效**并自动保存。

## 🖱️ 操作速览

* **拖动窗口**：按住窗口任意位置拖动。
* **单击浮窗**：隐藏（双击同样隐藏）。
* **右键浮窗**：显示指标 / 显示表头 / 显示网格 / 默认颜色 / **显示配置按钮** / **自定义名称…（右键在表格某一行上时）** / 设置… / 隐藏浮窗。
* **点击表头**：按该指标排序（降 → 升 → 取消），不触发拖动或隐藏窗口。
* **点击右下角 ⚙**：打开「自定义配置」（排序 + 自定义名称）；点它不会隐藏窗口。
* **系统托盘**：左键显示/隐藏；右键 **显示/隐藏 · 定位浮窗 · 设置… · 退出**。
  * 找不到浮窗时（例如开启贴边隐藏被收起、或处于非显示时段），用托盘右键 **「定位浮窗」**：会把它移到屏幕居中并强制显示 10 秒。
* **非交易时段**：若「请求时段」设成 `market`（09:15–15:00），盘外启动且**还没有任何数据**时浮窗显示灰色「非交易时段」提示；一旦请求到数据（或已有上次数据）就只显示数据、不再提示。
* **全局快捷键**：默认 `Ctrl+Alt+F` 显示/隐藏。

## 🌐 数据来源

行情通过 `QNetworkAccessManager` 从**新浪财经**接口（`hq.sinajs.cn`）获取（GBK 解码）。程序仅发起 GET 请求，不含任何账户/交易操作；请根据自身网络环境决定是否使用代理或更换数据源。

配置文件位于 `%APPDATA%\StockWidget\SW_config.json`，**与原版格式兼容**，可直接沿用原有配置。
